الخطة الهندسية والتشغيلية لبوت كلية الحاسبات والمعلومات

معمارية سحابية مجانية فائقة السرعة على شبكة Cloudflare العالمية مع تحكم كامل لليدرات من تيليجرام

⚡ 1. المعمارية السحابية: لماذا هذه التركيبة هي الأسرع والأكثر استقراراً؟

تم بناء النظام لخدمة آلاف الطلاب في نفس اللحظة (خصوصاً ليلة الامتحان) بدون أي تأخير في الاستجابة وبدون أي تكلفة استضافة، بالاعتماد على معمارية Edge Serverless فائقة الأداء:

المكون التقني التقنية المختارة الميزات التشغيلية والحدود المجانية
منصة التشغيل (Hosting) Cloudflare Workers تعمل بنظام Webhooks بزمن تشغيل 0 مللي ثانية (Zero Cold Start). لا تنام أبداً وتمنح 100,000 طلب يومياً مجاناً بدون الحاجة لفيزا.
قاعدة البيانات (Database) Cloudflare D1 (SQLite) مدمجة سحابياً بمساحة 5 جيجابايت، تدعم 5 مليون قراءة و 100 ألف كتابة يومياً، وتستجيب للاستعلامات في أقل من 1 مللي ثانية.
إطار البرمجة (Framework) grammY (TypeScript) أخف وأحدث مكتبة برمجية لـ Telegram API، مصممة خصيصاً للبيئات السحابية فائقة السرعة بدون استهلاك ذاكرة أو معالج.
تخزين الملفات (Storage) Telegram Servers + Archive تخزين لا نهائي ومجاني للملفات عبر كود file_id وقناة أرشيف خاصة، بدون حجز 1 ميجابايت على السيرفر.
💡 المقارنة مع المنصات التقليدية: منصات مثل Render و Heroku تدخل في وضع السكون (Sleep Mode) بعد دقائق من عدم الاستخدام وتتأخر 40 ثانية عند فتح البوت. أما ثنائي Cloudflare Workers و D1 فيبقى يقظاً دائماً 24/7 ويستجيب للضغطات في أقل من 50 مللي ثانية.
🌳 2. الشجرة الأكاديمية الديناميكية (Hierarchy Tree)

النظام لا يعتمد على أي أسماء ثابتة في الكود (No Hardcoding)، بل يعتمد على شجرة هرمية مرنة قابلة للتوسيع والتعديل بالكامل:

🏛️ المستوى 1 & 2: الأقسام والترم

الأقسام الأربعة الرئيسية (CS, IT, IS, Networks) مع خياري الترم الأول والترم الثاني بتنسيق أزرار عريضة وواضحة.

📚 المستوى 3: المقررات الدراسية

المواد الخاصة بكل قسم وترم (مثل: Compiler, Network Management, Advanced OS, Software Verification, وغيرها).

📂 المستوى 4: التصنيفات القياسية

خانات موحدة لكل مادة: المحاضرات (صف عريض)، السكاشن والعملي، الملخصات، الميدتيرم، وامتحانات الفاينال.

📄 المستوى 5: المحاضرات والملفات

المجلدات الفرعية للمحاضرات والسكاشن المرتبة تصاعدياً مع إمكانية استلام الملفات بنقرة زر واحدة.

👥 3. تجربة المستخدمين ونظام الصلاحيات المخصص (RBAC)

تم بناء نظام أمان متقدم متعدد المستويات (Role-Based Access Control) لحماية المحتوى وتوزيع المهام بدقة بين الطلاب والليدرز:

نوع المستخدم الأزرار المعروضة على الشاشة الصلاحيات والوظائف المتاحة
طالب (Student) أزرار الأقسام والمواد فقط + أزرار التنقل السريع. تصفح المواد واستلام الملفات فوراً دون أي أزرار تحكم أو إعلانات مشوشة.
ليدر قسم (Leader) أزرار الطالب + شريط الإدارة في أسفل القائمة: [📤 رفع ملفات], [➕ إضافة خانة], [✏️ تعديل], [🗑️ حذف]. إدارة كاملة (رفع، تعديل، حذف) داخل الأقسام المخصصة له فقط (مثل CS فقط)، ويعامله البوت كطالب عادي خارجها.
المسؤول العام (Super Admin) كافة أزرار التحكم في جميع الأقسام + أوامر الإدارة الحصرية: /admin و /leaders. تحكم شامل في كل أقسام الكلية، تعيين الليدرز وتحديد أقسامهم بضغطة زر، وإدارة قناة الأرشيف والتنسيق العام.
✨ 4. الميزات الإضافية المتقدمة التي تم تطويرها في المشروع

خلال مرحلة التطوير، تمت إضافة مجموعة من الميزات النوعية لضمان أفضل سرعة وسلاسة في الاستخدام:

🎓 وضع الدخول المزدوج (Dual Mode)

إمكانية انتقال المشرف بضغطة زر بين وضع الطالب (لرؤية النتيجة النهائية النظيفة) ووضع المشرف لإظهار أدوات التحكم.

⚡ الحذف الفوري المتعدد (Multi-Delete)

إمكانية حذف عدة ملفات متتالية دون انغلاق القائمة، مع حذف الملف من قناة الأرشيف ومن قاعدة البيانات في أجزاء من الثانية.

🤫 الرفع الجماعي الصامت (Silent Upload)

إرسال أو تحويل عشرات الملفات والصور دفعة واحدة دون رسائل تشويش متكررة، مع تأكيد الحفظ بنقرة واحدة عند الانتهاء.

📦 تحميل المادة بالكامل (Download All)

زر تجميع ذكي [📦 عرض وتحميل كل المحتوى] يجمع ويرسل كل محاضرات وسكاشن المادة مصنفة دفعة واحدة.

🎯 التسليم الذكي للملفات (Leaf Delivery)

عند ضغط الطالب على محاضرة نهائية، ترسل الملفات فوراً مع إبقاء أزرار المحاضرات متاحة للتنقل دون فتح صفحات فارغة.

📐 تخصيص العرض والصفوف (Layout Control)

التحكم في عرض كل زر (صف عريض 🔘 ↔️ صف مزدوج 👥) مع زر تعميم التنسيق على باقي المواد لتنظيم الواجهة.

🔔 اشتراك الأقسام والتنبيهات (Subscriptions)

زر دائم بشاشة البداية لاشتراك الطالب في قسمه مع كتم أو تفعيل التنبيهات، وتنبيه تلقائي بنقرة واحدة بعد رفع الملفات.

📢 التعميم الآمن المجدول (Cron Broadcast)

إرسال تعميمات القسم عبر طابور بالخلفية (35 طالب/دقيقة) لضمان البقاء تحت قيود كلاودفلير وتيليجرام مع كتم المحظورين.

🗄️ 5. التصميم الهندسي لقاعدة البيانات (D1 SQL Schema)

مخطط قاعدة بيانات سحابية متكاملة وسريعة تعتمد على محرك SQLite المدمج داخل شبكة Cloudflare:

-- 1. جدول المستخدمين والصلاحيات والإشعارات CREATE TABLE users ( telegram_id INTEGER PRIMARY KEY, full_name TEXT, role TEXT DEFAULT 'student', -- 'student' | 'leader' | 'super_admin' managed_node_id INTEGER DEFAULT NULL, current_node_id INTEGER DEFAULT NULL, -- معرف المجلد الحالي للرجوع السلس bot_state TEXT DEFAULT 'browsing', -- حالة المحادثة view_mode TEXT DEFAULT 'admin', -- 'admin' | 'student' subscribed_dept_id INTEGER DEFAULT NULL,-- معرّف القسم المشترك به notifications_enabled INTEGER DEFAULT 1 -- 1: مفعل | 0: مكتوم / محظور ); -- 2. الشجرة الهرمية للأقسام والمواد CREATE TABLE nodes ( id INTEGER PRIMARY KEY AUTOINCREMENT, parent_id INTEGER DEFAULT NULL, -- معرف المجلد الأب (NULL للأقسام الرئيسية) title TEXT NOT NULL, -- نص الزر sort_order INTEGER DEFAULT 0, -- ترتيب العرض التصاعدي created_by INTEGER, is_full_width INTEGER DEFAULT 0, -- 1: صف عريض منفرد | 0: صف مزدوج FOREIGN KEY (parent_id) REFERENCES nodes(id) ON DELETE CASCADE ); -- 3. المحتوى والملفات الأكاديمية المرفوعة CREATE TABLE materials ( id INTEGER PRIMARY KEY AUTOINCREMENT, node_id INTEGER NOT NULL, -- معرف المجلد التابع له file_name TEXT NOT NULL, -- اسم الملف الأصلي telegram_file_id TEXT NOT NULL, -- معرّف تيليجرام الدائم file_type TEXT NOT NULL, -- 'document' | 'video' | 'photo' | 'audio' caption TEXT DEFAULT NULL, uploaded_by INTEGER, created_at DATETIME DEFAULT CURRENT_TIMESTAMP, backup_message_id INTEGER DEFAULT NULL,-- معرّف الرسالة بقناة الأرشيف للحذف التلقائي FOREIGN KEY (node_id) REFERENCES nodes(id) ON DELETE CASCADE ); -- 4. تخصيص صلاحيات الأقسام لليدرز (RBAC) CREATE TABLE user_permissions ( telegram_id INTEGER NOT NULL, node_id INTEGER NOT NULL, -- معرف القسم المصرح به PRIMARY KEY (telegram_id, node_id) ); -- 5. طابور مهام الإرسال المجدول (Broadcast Jobs Queue) CREATE TABLE broadcast_jobs ( id INTEGER PRIMARY KEY AUTOINCREMENT, dept_node_id INTEGER NOT NULL, dept_title TEXT NOT NULL, sender_id INTEGER NOT NULL, from_chat_id INTEGER NOT NULL, message_id INTEGER NOT NULL, last_user_id INTEGER DEFAULT 0, sent_count INTEGER DEFAULT 0, failed_count INTEGER DEFAULT 0, status TEXT DEFAULT 'pending', -- 'pending' | 'processing' | 'completed' created_at DATETIME DEFAULT CURRENT_TIMESTAMP ); CREATE INDEX idx_nodes_parent_order ON nodes(parent_id, sort_order); CREATE INDEX idx_materials_node ON materials(node_id); CREATE INDEX idx_users_sub ON users(subscribed_dept_id, notifications_enabled, telegram_id); CREATE INDEX idx_broadcast_status ON broadcast_jobs(status, id);

📋 7. الدليل المرجعي للأوامر (Command Reference)

تم تخصيص الأوامر في تيليجرام بحيث لا تظهر أوامر الإدارة إلا للمسؤول العام فقط عند كتابة /:

الأمر الوصف والوظيفة الصلاحية
/start فتح القائمة الرئيسية وتبديل الوضع (طالب 🎓 / مشرف ⚙️). متاح للجميع
/notifications إعدادات الإشعارات وتحديد واشتراك القسم الأكاديمي. متاح للجميع
/id معرفة الـ Telegram ID الخاص بالحساب ونسخه بلمسة واحدة. متاح للجميع
/admin لوحة تحكم المسؤول العام (قناة الأرشيف، حالة النظام، إدارة الليدرز). المسؤول العام فقط 🔒
/leaders عرض وتعديل صلاحيات الليدرز الممنوحة لكل قسم بضغطة زر. المسؤول العام فقط 🔒
/promote <ID> ترقية مستخدم إلى رتبة ليدر وتعيين أقسامه المخصصة فوراً. المسؤول العام فقط 🔒
/demote <ID> سحب رتبة الليدر وحذف كافة صلاحيات الأقسام من المستخدم. المسؤول العام فقط 🔒
💡 ميزة التحويل المباشر: لتعيين أي ليدر جديد دون كتابة الـ ID الخاص به، يمكنك فقط الضغط على زر [➕ تعيين ليدر جديد] في البوت وعمل Forward (تحويل) لأي رسالة منه للبوت مباشرة، وسيقوم البوت باستخراج بياناته وترقيته فوراً.
